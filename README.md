# Campus Skill Exchange

Campus Skill Exchange is a Django web application where students can share their skills and explore skills shared by other students.

## Features

- User login
- Add and share skills
- Explore skills shared by students
- View personal profile
- Django authentication
- SQLite database

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS

## Project Structure

- `manage.py` – Django project management file
- `fdsdemo/` – Main Django project
- `myapp/` – Application containing models and views
- `templates/` – HTML pages
- `db.sqlite3` – SQLite database

## How to Run

```bash
python3 manage.py runserver
